# Spice Route Admin

A Pakistani restaurant website with a built-in admin panel for menu and point-of-sale operations.

## Development

Requires Node.js and npm.

```sh
npm i
npm run dev
```

Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` for the browser client. Server-side features may also require `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, and `SUPABASE_SERVICE_ROLE_KEY`.
